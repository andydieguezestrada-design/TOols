# TOols V31.4 — Permissions & Device Control

- Expanded Android permission manifest for TOols capabilities.
- Added shared-storage all-files access, media permissions including Android 14 user-selected media.
- Added camera, microphone, location and Bluetooth runtime permissions.
- Added optional Contacts and Calendar runtime permissions.
- Added special-access controls for Accessibility automation, overlay, usage access and APK installation.
- Added foreground-service/wake-lock declarations for long-running agent work.
- Added explicit TOolsAccessibilityService; it performs no action unless the user enables the service in Android Settings.
- Reworked Settings into a real Permissions & Device Access Center.
- Version 3.1.4 / code 35.
