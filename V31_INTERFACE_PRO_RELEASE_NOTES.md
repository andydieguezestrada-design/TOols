# TOols V31 — Interface PRO inspired by the supplied reference

This release keeps the TOols V30 agent/build functionality and redesigns the main dashboard with a premium light interface inspired by the supplied visual reference:

- Soft white/lavender visual system with rounded cards and subtle elevation.
- Strong hero card for the AI Agent.
- Quick actions for New Project, Import and AI Agent.
- Workspace health/progress card.
- Project cards with cleaner hierarchy.
- Bottom navigation for Files, Terminal, AI, Providers and Profile/Settings.
- Light theme is now the default; the existing dark color scheme remains available through `TOolsTheme(darkTheme = true)`.
- No external images or network assets are required for the redesign.
- Existing V30 agent, file manager, GitHub, build and provider functionality is preserved.

Version: 3.1.0 / code 31
