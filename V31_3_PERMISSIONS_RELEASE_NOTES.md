# TOols V31.3 — Permission & Device Access

- Added explicit permission center in Settings.
- Added Android 13+ READ_MEDIA_IMAGES/VIDEO/AUDIO and legacy storage permissions for Android 12 and below.
- Added MANAGE_EXTERNAL_STORAGE special-access flow for full shared-storage/file-manager operation.
- Added Camera and Microphone runtime permission controls for attachment/voice features.
- Added Notifications permission control.
- Clarified that INTERNET/ACCESS_NETWORK_STATE are normal manifest permissions and do not show a runtime dialog.
- Version 3.1.3 / code 34.
